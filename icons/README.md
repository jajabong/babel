# Chrome Extension Icons

You need to create the following PNG icon files for the Chrome extension:

## Required Icons:

- icon16.png (16x16 pixels)
- icon32.png (32x32 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

## Design Guidelines:

- Use a purple gradient background (#667eea to #764ba2)
- Include a brain or magic wand icon
- Keep the design clean and simple
- Ensure good contrast at small sizes

## Temporary Solution:

For testing purposes, you can:

1. Download any 16x16, 32x32, 48x48, 128x128 PNG icons
2. Or remove the icon references from manifest.json temporarily

## Recommended Icon Creation Tools:

- **Online**: Canva, Figma, or icon generators
- **Desktop**: Adobe Illustrator, Sketch, or GIMP
- **Simple**: Use the Chrome Extension Icon Generator online

The icons should represent "AI prompt optimization" with a modern, professional look.
